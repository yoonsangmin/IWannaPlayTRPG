# IWannaPlayTRPG

- 언리얼 블루프린트를 사용한 CRPG 프로토타입 프로젝트
- 언리얼 엔진 블루프린트의 다양한 기능들을 활용해서 CRPG 게임의 기본적인 기능들을 구현했습니다.

### 진행 기간 
2025.03.19 ~ 2025.03.26

### 기술 스택
- 언리얼 엔진 5.4, 블루프린트, 위젯, NavMesh, 데이터테이블, Git
- 블루프린트를 사용하여 빠르게 로직을 작성해 프로토타입을 구현하였습니다.

### 프로젝트 진행 단계
1. 카메라 기본 조작
- WASD 키를 통해 카메라 이동 구현
- 마우스 가운데 클릭으로 카메라 회전 구현
- 스플라인 컴포넌트를 사용하여 커스텀 가능한 줌 기능 구현
- 카메라를 유닛 위치에 고정하는 기능을 구현하여 플레이어가 특정 유닛을 쉽게 따라가도록 설정
2. 플레이어 유닛 이동 시스템 구현
- 유닛에 AI 컨트롤러를 할당해서 카메라와 유닛을 분리
- 내비 메시와 AI Move To 노드를 사용하여 왼쪽 마우스 클릭 시 플레이어 유닛 이동하도록 구현
3. 유닛 데이터 테이블 구현
- 체력, 공격력, 이동 가능한 거리, 민첩성 등의 유닛의 정보를 데이터 테이블로 관리할 수 있도록 구조체 구성 및 데이터 테이블 생성
- 각 유닛의 능력치를 FName 키 값을 통해 불러올 수 있도록 설정
- Soft Reference를 사용하여 필요한 에셋만 동적으로 로드할 수 있도록 성능 최적화
4. 위젯 구현
- 전투 중 유닛의 현재 턴인 유닛과 체력 등의 정보를 표시하는 UI 위젯을 구현
- 전투 중 이동 가능한 거리, 공격 범위를 표시하는 UI 구현
- 위젯 내부의 변수 변경 시 자동으로 UI 업데이트 되도록 업데이트되도록 Notify 활용
5. 전투 및 턴 시스템 구현
- 민첩성을 기준으로 퀵 정렬을 통해 턴 순서를 설정
- 이동 페이즈와 공격 페이즈 구현
- 언리얼 대미지 시스템을 사용하여 피해를 입히도록 구현
- 턴 진행 및 전투 승리 조건 확인 후 전투 종료 구현


###  문제 해결 과정 
- 카메라 조작 문제
  - 카메라의 이동 범위가 제한 없이 움직이는 문제를 해결하기 위해 카메라의 이동 범위를 맵 크기와 유닛 위치에 맞춰 제한했습니다.
- 이동 제한 오류
  - 유닛의 이동 범위가 정확하게 계산되지 않는 문제를 해결하기 위해 유닛이 매프레임 실제로 이동한 경로를 합산해서 이동 거리가 정확하게 반영되도록 수정했습니다.
- 이동 편의성 문제
  - 이동 범위 밖으로 이동하려고 할 때 이동이 불가능 한 문제가 있었습니다. Find Path to Location Synchronously 노드를 사용해서 길 찾기 시스템의 경로를 얻어온 후 각 구간의 거리를 합산해서 이동 가능한 거리를 초과할 시 이동 가능한 최대 거리의 위치를 길찾기 위치로 설정하도록 구현했습니다.
- UI 동기화 문제
  - 위젯 블루프린트에서 bool 변수의 값이 변경될 때 Notify가 호출되지 않는 문제가 발생했습니다. 해당 문제를 해결하기 위해 별도의 이벤트를 호출하도록 구현했습니다.
- 프로젝트 실행 문제
  - 프로젝트가 블루프린트 오류 때문에 안 켜지는 문제가 있었습니다. 해당 블루프린트 에셋을 제외하고 프로젝트를 켠 후에 이전 백업된 버전에 옮기는 작업을 했습니다.

### 개선할 사항 
 - AI에 비헤이비어 트리와 EQS를 사용해 좀 더 다양한 AI 이동 및 시스템 구현
 - 복잡한 플레이어 스탯, 대화창 등 CRPG에 기능 확장
